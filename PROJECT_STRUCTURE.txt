DEPLOYMENT OPTIONS
==================

Option 1: GitHub + Desktop
  - Push entire project to GitHub
  - Users can build desktop app
  - Share web version via GitHub Pages

Option 2: GitHub + Web Only  
  - Share only web version URL
  - Friends don't need to build
  - Perfect for quick sharing

Option 3: Local Desktop
  - Build desktop app locally
  - Share with colleagues

QUICK START
===========

Test Web Version:
  cd docs && python3 -m http.server 8000
  -> Visit http://localhost:8000

Deploy to GitHub:
  1. Create GitHub account (if needed)
  2. Create "tezcrypt" repository
  3. Push code: git push
  4. Enable Pages (source: /docs)
  5. Share: https://username.github.io/tezcrypt

Your web version is live in < 30 minutes!
